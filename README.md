# MATER.IA — Landing Page

Landing page para **MATER.IA**, una iniciativa del Gobierno de la Ciudad de Buenos Aires orientada a preparar a la próxima generación para un mercado laboral transformado por la inteligencia artificial.

## 🚀 Estructura

```
materia-landing/
├── index.html          # Página principal (one-pager)
├── css/
│   └── styles.css      # Estilos con CSS variables
├── js/
│   └── main.js         # Interactividad y animaciones
├── img/                # Imágenes y logotipos
└── README.md
```

## 🎨 Stack Tecnológico

- **HTML5** semántico
- **CSS3** con variables custom (sin frameworks)
- **JavaScript** ES6+ (sin dependencias)
- **Google Fonts**: Poppins + Inter

## 📐 Secciones

1. **Hero** — Portada con headline de impacto y CTAs
2. **El Problema** — Contexto sobre la obsolescencia educativa
3. **Los Datos** — 3 estadísticas animadas con counter
4. **El Nuevo Valor Humano** — Capacidades que la IA no reemplaza
5. **Qué es MATER.IA** — Filosofía del proyecto
6. **La Experiencia Interior** — 3 estaciones del trailer
7. **Sumate** — Formulario de contacto
8. **Footer** — Créditos y redes sociales

## 📱 Responsive

- Mobile first (375px → 1920px)
- Navbar hamburger en mobile
- Carrusel horizontal en sección experiencia (mobile)

## ♿ Accesibilidad

- WCAG AA contraste mínimo
- Atributos `alt` en todas las imágenes
- Navegación por teclado con `focus-visible`
- Etiquetas semánticas: `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`
